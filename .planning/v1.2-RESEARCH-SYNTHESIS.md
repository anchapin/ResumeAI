## 1. Job Match Scoring (ANA-01 to ANA-04)

### Recommended Approach

**Hybrid Sentence Transformer + Weighted Keyword Matching**

| Component | Technology | Weight |
|-----------|-----------|--------|
| **Semantic Similarity** | sentence-transformers (`all-MiniLM-L6-v2`) | 40% |
| **Skills Match** | spaCy NER + skill ontology | 35% |
| **Experience Match** | Years extraction + comparison | 15% |
| **Education Match** | Level mapping (HS → Bachelor → Master → PhD) | 10% |

### Why This Approach

- **Accuracy:** 80-90% correlation with human ratings (vs 60-70% for TF-IDF alone)
- **Latency:** 60-250ms per comparison on CPU
- **Cost:** Free (self-hosted), no API fees
- **Privacy:** Processes locally, no data sent to external APIs

### Scoring Formula

```python
def calculate_match_score(resume_text: str, job_description: str) -> float:
    # 1. Semantic Similarity (40%)
    semantic_score = cosine_similarity(resume_emb, jd_emb)[0][0]
    semantic_normalized = (semantic_score + 1) / 2  # [-1,1] → [0,1]
    
    # 2. Skills Match (35%)
    matched = resume_skills.intersection(jd_skills)
    skills_score = len(matched) / len(jd_skills)
    
    # 3. Experience Match (15%)
    experience_score = min(1.0, resume_years / jd_years)
    
    # 4. Education Match (10%)
    education_score = 1.0 if resume_edu >= jd_edu else 0.5
    
    # Final score
    final = (semantic_normalized * 0.40 +
             skills_score * 0.35 +
             experience_score * 0.15 +
             education_score * 0.10)
    
    return round(final * 100, 1)  # 0-100 scale
```

|-------|--------|------------------|
| **Images/Graphics** | Garbled characters (`$&%#*`) | `page.images` (PDF), `inline_shapes` (DOCX) |

### Detection Strategy

**PDF Analysis (pdfplumber):**

```python
import pdfplumber

def analyze_pdf_resume(filepath: str) -> dict:
    issues = []
    
    with pdfplumber.open(filepath) as pdf:
        for page in pdf.pages:
            # Detect images
            if page.images:
                issues.append({
                    'type': 'CRITICAL',
                    'element': 'images',
                    'count': len(page.images)
                })
            
            # Detect tables
            tables = page.find_tables()
            if tables and (len(tables[0].rows) > 2 or len(tables[0].columns) > 2):
                issues.append({
                    'type': 'WARNING',
                    'element': 'complex_table'
                })
            
            # Check header/footer for contact info
            header_zone = page.crop((0, 0, page.width, page.height * 0.15))
            if extract_contact_info(header_zone.extract_text()):
                issues.append({
                    'type': 'CRITICAL',
                    'element': 'contact_in_header'
                })
            
            # Detect scanned PDF
            if not page.chars:
                issues.append({
                    'type': 'CRITICAL',
                    'element': 'scanned_pdf'
                })
    
    return {'issues': issues}
```

**DOCX Analysis (python-docx):**

```python
from docx import Document

def analyze_docx_resume(filepath: str) -> dict:
    issues = []
    doc = Document(filepath)
    
    # Detect tables
    if doc.tables:
        for table in doc.tables:
            if len(table.rows) > 2 or len(table.columns) > 2:
                issues.append({
                    'type': 'WARNING',
                    'element': 'complex_table'
                })
    
    # Detect images
    if doc.inline_shapes:
        issues.append({
            'type': 'CRITICAL',
            'element': 'images'
        })
    
    # Check headers/footers
    for section in doc.sections:
        if extract_contact_info(section.header.text):
            issues.append({
                'type': 'CRITICAL',
                'element': 'contact_in_header'
            })
    
    return {'issues': issues}
```

### Scoring Algorithm

```python
def calculate_ats_score(issues: list) -> int:
    """
    Calculate ATS compatibility score (0-100).
    
    Deductions:
    - CRITICAL: -25 points each
    - WARNING: -10 points each
    - INFO: -5 points each
    """
    WEIGHTS = {'CRITICAL': 25, 'WARNING': 10, 'INFO': 5}
    
    base_score = 100
    deductions = sum(WEIGHTS.get(issue['type'], 5) for issue in issues)
    
    return max(0, base_score - deductions)

# Interpretation:
# 80-100: GOOD - Will likely reach recruiter
# 50-79: FAIR - May have parsing issues
# 20-49: POOR - Significant parsing problems
# 0-19: CRITICAL - Will likely be rejected by ATS
```

## 5. A/B Testing (ANA-17 to ANA-20)

### Statistical Approach

**Chi-Squared Test for Significance:**

```python
from scipy import stats

def calculate_significance(variant_a: dict, variant_b: dict) -> dict:
    """
    variant_a = {'applications': 20, 'interviews': 1}
    variant_b = {'applications': 30, 'interviews': 4}
    """
    # Contingency table
    #            Interview  No Interview
    # Variant A      1          19
    # Variant B      4          26
    
    observed = [
        [variant_a['interviews'], variant_a['applications'] - variant_a['interviews']],
        [variant_b['interviews'], variant_b['applications'] - variant_b['interviews']]
    ]
    
    chi2, p_value, dof, expected = stats.chi2_contingency(observed)
    
    is_significant = p_value < 0.05
    confidence = 1 - p_value
    
    return {
        'p_value': p_value,
        'chi_squared': chi2,
        'is_significant': is_significant,
        'confidence': f"{confidence:.1%}",
        'recommendation': 'Variant B is performing better' if is_significant else 'Not enough data'
    }
```

### Minimum Sample Size

**Rule of Thumb:**

| Baseline Rate | Detect 50% Improvement | Detect 100% Improvement |
|---------------|------------------------|-------------------------|
| 2% interview rate | ~2,000 applications per variant | ~500 applications per variant |
| 5% interview rate | ~800 applications per variant | ~200 applications per variant |
| 10% interview rate | ~400 applications per variant | ~100 applications per variant |

**Practical Guidance:**
- Most users won't reach statistical significance in v1.2
- Show "trend" indicators instead of "significant" claims
- Require minimum 20 applications per variant before showing comparison

### Auto-Pause Logic

```python
def should_auto_pause(variant: dict, all_variants: list) -> bool:
    """
    Auto-pause underperforming variant.
    
    Criteria:
    - At least 20 applications
    - Interview rate < 50% of best variant
    - Difference is statistically significant (p < 0.05)
    """
    if variant['applications'] < 20:
        return False
    
    best_variant = max(all_variants, key=lambda v: v['interview_rate'])
    
    if variant['interview_rate'] < 0.5 * best_variant['interview_rate']:
        significance = calculate_significance(variant, best_variant)
        if significance['is_significant']:
            return True
    
    return False
```
