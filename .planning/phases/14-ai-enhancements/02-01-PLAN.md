# Phase Plan: v1.4 Phase 2 - Skills Extraction

**Version:** 1.0
**Created:** 2026-03-13
**Status:** Ready for Execution

---

## Phase Overview

**Goal:** Automatically extract and map skills from job descriptions to resume sections.

**Requirements:**
- **AI-04:** Skills extraction from job descriptions
- **AI-05:** Skills mapping to resume sections
- **AI-06:** Missing skills identification

**Success Criteria:**
1. Extract skills from JD text (NLP-based)
2. Categorize skills (technical, soft, tools, domain)
3. Map extracted skills to resume sections
4. Identify missing skills not in resume
5. Suggest where to add missing skills
6. Confidence scores for skill matches

**Estimated Effort:** 4-5 weeks (3-4 days backend, 3-4 days frontend)

---

## Architecture

### Backend Services

```
resume-api/
├── lib/
│   └── skills/
│       ├── __init__.py
│       ├── extractor.py          # SkillsExtractor (NLP + LLM)
│       ├── matcher.py            # SkillsMatcher (resume mapping)
│       ├── ontology.py           # Skills ontology database
│       ├── categorizer.py        # SkillsCategorizer
│       └── models.py             # Data models
├── routes/
│   └── skills.py                 # API endpoints
└── tests/
    └── skills/
        ├── test_extractor.py
        ├── test_matcher.py
        ├── test_categorizer.py
        └── test_integration.py
```

### API Endpoints

```
POST /api/v1/skills/extract       # Extract skills from JD
POST /api/v1/skills/match         # Match skills to resume
GET  /api/v1/skills/gap           # Skills gap analysis
GET  /api/v1/skills/categories    # Get skill categories
```

### Frontend Components

```
src/components/skills/
├── SkillsGapAnalysis.tsx         # Main gap analysis UI
├── SkillCategory.tsx             # Category display
├── SkillMatchCard.tsx            # Individual skill match
├── MissingSkillItem.tsx          # Missing skill suggestion
└── hooks/
    ├── useSkillsExtraction.ts
    └── useSkillsGap.ts
```
