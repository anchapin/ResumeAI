**Version:** 1.0
**Created:** 2026-03-13
**Status:** Ready for Execution

## Phase Overview

**Goal:** Provide overall resume quality scoring with actionable improvement recommendations.

**Requirements:**
- **AI-10:** Overall resume quality score (0-100)
- **AI-11:** Category-specific scores (experience, skills, education, formatting)
- **AI-12:** Actionable improvement recommendations

**Success Criteria:**
1. Overall resume quality score (0-100)
2. Category scores (experience, skills, education, formatting)
3. Specific, actionable improvement recommendations
4. Priority ranking (high/medium/low impact)
5. Track score improvement over time
6. Benchmark against similar roles/industries

**Dependencies:** Phase 1 (writing assistant), Phase 2 (skills extraction)

**Estimated Effort:** 3-4 weeks (3-4 days backend, 3-4 days frontend)

## Architecture

### Backend Services

```
resume-api/
├── lib/
│   └── scoring/
│       ├── __init__.py
│       ├── resume_scorer.py      # ResumeScorer (main scoring engine)
│       ├── category_scorers.py   # Category-specific scorers
│       ├── recommender.py        # RecommendationEngine
│       ├── benchmarks.py         # IndustryBenchmarkService
│       └── models.py             # Data models
├── routes/
│   └── scoring.py                # API endpoints
└── tests/
    └── scoring/
        ├── test_resume_scorer.py
        ├── test_category_scorers.py
        ├── test_recommender.py
        └── test_integration.py
```

### API Endpoints

```
POST /api/v1/scoring/score        # Get resume score
GET  /api/v1/scoring/breakdown    # Category breakdown
GET  /api/v1/scoring/recommendations # Get recommendations
GET  /api/v1/scoring/benchmarks   # Industry benchmarks
POST /api/v1/scoring/track        # Track score over time
```

### Frontend Components

```
src/components/scoring/
├── ResumeScoreCard.tsx           # Main score display
├── CategoryBreakdown.tsx         # Category scores
├── RecommendationsList.tsx       # Recommendations list
├── ScoreTrendChart.tsx           # Score over time
├── BenchmarkComparison.tsx       # Industry comparison
└── hooks/
    ├── useResumeScore.ts
    └── useScoreTracking.ts
```
