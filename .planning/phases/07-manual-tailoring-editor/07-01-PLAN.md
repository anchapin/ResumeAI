# Phase 7: Manual Tailoring Editor - Plan 01

**Goal:** Create rich text editor interface for manual editing of AI-tailored resume and cover letter content.

**Requirement:** JOB-07

**Success Criteria:**
1. Rich text editor component integrated into resume editor
2. Toolbar with formatting options (bold, italic, lists, links)
3. Edit/preview toggle for resume sections
4. Real-time content updates in store
5. Cover letter editor with same capabilities

**Dependencies:** Phase 3 (AI Tailoring), Phase 4 (Cover Letter)

**Out of Scope:** Version history (Plan 02), Change tracking (Plan 03)

---

## Tasks

### Task 1: Research Editor Library

**What:** Evaluate and select rich text editor library for React

**Options to consider:**
- TipTap (recommended - modern, headless, good TypeScript support)
- Slate.js (flexible but steeper learning curve)
- Draft.js (deprecated by Facebook)
- Quill (simpler but less customizable)

**Verification:**
- Library selected and documented in decision log
- Package installed via npm

**Automation:** Claude will research and recommend best option

---

### Task 2: Create RichTextEditor Component

**What:** Build reusable rich text editor wrapper component

**Implementation:**
- Create `src/components/editor/RichTextEditor.tsx`
- Wrap selected library with React interface
- Add toolbar configuration props
- Support controlled/uncontrolled modes
- Add TypeScript types for editor value

**Verification:**
- Component renders with toolbar
- Basic formatting (bold, italic) works
- TypeScript compilation passes
- Unit tests pass

**Files to create:**
- `src/components/editor/RichTextEditor.tsx`
- `src/components/editor/RichTextEditor.test.tsx`
- `src/components/editor/index.ts`

### Task 3: Add Editor Mode Toggle to Resume Sections

**What:** Enable edit/preview mode for each resume section

**Implementation:**
- Add `isEditing` state to resume sections
- Add toggle button (Edit/Preview) to section headers
- Conditional rendering: RichTextEditor vs read-only view
- Wire content updates to Zustand store

**Verification:**
- Edit button visible on experience, education, skills sections
- Clicking Edit shows rich text editor
- Clicking Preview shows formatted content
- Changes persist in store

**Files to modify:**
- `src/components/resume/ResumeSection.tsx`
- `src/components/resume/ExperienceItem.tsx`
- `src/components/resume/SkillsSection.tsx`

---

### Task 4: Wire Editor to Zustand Store

**What:** Connect editor changes to resume data store

**Implementation:**
- Add `updateSectionContent` action to resume store
- Debounce saves to prevent excessive updates
- Add `saveStatus` state (idle, saving, saved, error)
- Show save indicator in UI

**Verification:**
- Editor changes update store immediately
- Save status indicator shows "Saving..." then "Saved"
- Changes persist across page refresh (localStorage)
- No console errors

**Files to modify:**
- `src/store/resume-store.ts`
- `src/components/editor/RichTextEditor.tsx`

---
