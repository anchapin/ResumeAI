**Matching Logic:**
```python
def matches(alert, job):
    # Query match (title, company, skills)
    if alert.query and not fuzzy_match(alert.query, job.title, job.description):
        return False
    
    # Remote filter
    if alert.remote is not None and job.remote != alert.remote:
        return False
    
    # Location filter
    if alert.location and not fuzzy_match(alert.location, job.location):
        return False
    
    # Salary filter
    if alert.min_salary and job.salary_max < alert.min_salary:
        return False
    
    return True
```

**Verification:**
