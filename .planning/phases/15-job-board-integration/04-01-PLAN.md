# Phase Plan: v1.5 Phase 4 - Unified Tracking

**Version:** 1.0
**Created:** 2026-03-13
**Status:** Ready for Execution

---

## Phase Overview

**Goal:** Track all job applications in one unified dashboard with status sync across job boards.

**Requirements:**
- **JOB-07:** Unified application tracking dashboard
- **JOB-08:** Auto-fill applications from resume data

**Success Criteria:**
1. Unified dashboard for all applications
2. Auto-track applications submitted through platform
3. Manual entry for external applications
4. Status sync with LinkedIn (where available)
5. Application analytics (conversion rates, time to response)
6. Auto-fill applications from resume data

**Dependencies:** Phase 2 (Job Aggregator) - for job data, Phase 1 (LinkedIn) - for status sync

**Estimated Effort:** 3-4 weeks backend, 3-4 weeks frontend

---

## Architecture

### Backend Services

```
resume-api/
├── lib/
│   └── tracking/
│       ├── __init__.py
│       ├── models.py             # Application, ApplicationStatus models
│       ├── tracker.py            # ApplicationTracker service
│       ├── autofill.py           # AutoFillService for applications
│       ├── analytics.py          # ApplicationAnalytics service
│       └── sync.py               # External sync (LinkedIn, etc.)
├── routes/
│   └── applications.py           # API endpoints
└── tests/
    └── tracking/
        ├── test_tracker.py
        ├── test_autofill.py
        └── test_integration.py
```

### API Endpoints

```
GET  /api/v1/applications          # List applications
POST /api/v1/applications          # Create application
GET  /api/v1/applications/{id}     # Get application
PUT  /api/v1/applications/{id}     # Update application
DELETE /api/v1/applications/{id}   # Delete application
POST /api/v1/applications/{id}/status # Update status
GET  /api/v1/applications/stats    # Application statistics
GET  /api/v1/applications/funnel   # Application funnel
POST /api/v1/applications/autofill # Auto-fill from resume
```

### Frontend Components

```
src/components/applications/
├── ApplicationsDashboard.tsx     # Main dashboard
├── ApplicationCard.tsx           # Individual application
├── ApplicationForm.tsx           # Create/edit form
├── ApplicationFunnel.tsx         # Funnel visualization
├── ApplicationStats.tsx          # Statistics display
└── hooks/
    ├── useApplications.ts
```

```python
class JobApplication(Base):
    # Existing fields
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"))
    job_id = Column(String, ForeignKey("job_postings.id"))
    status = Column(String)  # draft, applied, screening, interviewing, offer, accepted, rejected, withdrawn
    
    # New fields for Phase 4
    external_id = Column(String)  # External application ID
    external_source = Column(String)  # LinkedIn, Indeed, Company site
    external_status = Column(String)  # Status from external source
    submitted_at = Column(DateTime)
    response_at = Column(DateTime)
    autofilled = Column(Boolean)  # Was auto-filled
    
    # Tracking
    days_in_status = Column(Integer)
    response_time_days = Column(Integer)
```
