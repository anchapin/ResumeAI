## Phase Overview

**Goal:** Implement LinkedIn OAuth 2.0 integration and expand profile import functionality.

**Requirements:**
- **JOB-01:** LinkedIn API integration (OAuth, profile)
- **JOB-02:** LinkedIn Easy Apply (application tracking alternative)

**Success Criteria:**
1. OAuth 2.0 authentication with PKCE working
2. Secure token storage with encryption
3. Automatic token refresh handling
4. Profile import expanded with more data
5. LinkedIn connection status display
6. Graceful degradation if LinkedIn unavailable

**Dependencies:** None (standalone feature, builds on existing GitHub OAuth)

**Estimated Effort:** 2 weeks backend, 2 weeks frontend

#### Task 1.2: OAuth 2.0 Implementation
**Type:** `backend`
**Effort:** 2 days

- [ ] Create `lib/linkedin/oauth.py`
- [ ] Implement PKCE code verifier/challenge:
  ```python
  def generate_code_verifier() -> str
  def generate_code_challenge(verifier: str) -> str
  ```
- [ ] Implement OAuth flow:
  - `initiate_oauth()` - Generate auth URL with PKCE
  - `handle_callback()` - Exchange code for tokens
  - `refresh_tokens()` - Refresh access tokens
  - `revoke_tokens()` - Disconnect/revoke access
- [ ] State parameter for CSRF protection
- [ ] Token encryption with Fernet
- [ ] Write unit tests

**OAuth Flow:**
```
1. User clicks "Connect LinkedIn"
2. Generate PKCE verifier/challenge
3. Redirect to LinkedIn OAuth URL
4. User authorizes
5. LinkedIn redirects back with code
6. Exchange code + PKCE for tokens
7. Store encrypted tokens
8. Fetch user profile
```

**Verification:**
- OAuth flow completes successfully
- Tokens encrypted at rest
- Tests pass with 80%+ coverage
