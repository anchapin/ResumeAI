## Phase Overview

**Goal:** Aggregate jobs from multiple sources and provide unified job search functionality.

**Requirements:**
- **JOB-03:** Job aggregator service (RSS, APIs, scraping)
- **JOB-04:** Unified job search across all sources

**Success Criteria:**
1. Aggregate jobs from 5+ sources
2. Unified search across all sources
3. Job recommendations based on profile
4. Filter by remote, location, salary
5. Save jobs for later
6. Deduplicate similar postings

**Dependencies:** Phase 1 (LinkedIn Integration) - for profile-based recommendations

**Estimated Effort:** 3-4 weeks backend, 3-4 weeks frontend

  - Company name matching
  - Location matching
  - URL hash comparison
- [ ] Configurable similarity threshold
- [ ] Write unit tests

**Deduplication Algorithm:**
```python
def are_duplicates(job1, job2):
    # Exact URL match (same job posted twice)
    if job1.url == job2.url:
        return True
    
    # Title + Company fuzzy match
    title_sim = fuzz.token_set_ratio(job1.title, job2.title)
    company_sim = fuzz.ratio(job1.company, job2.company)
    
    # Both must be high confidence
    return title_sim > 85 and company_sim > 90
```

**Verification:**
- Correctly identifies duplicates
- Keeps best version (most complete data)
- Tests pass
