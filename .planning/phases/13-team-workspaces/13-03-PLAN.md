<task type="auto">
  <name>Task 2: Create sharing endpoints</name>
  <files>resume-api/routes/resume_sharing.py</files>
  <action>
Create resume sharing API endpoints:
- POST /api/v1/resumes/{id}/share - Share resume with team
- GET /api/v1/resumes/{id}/share - Get sharing settings
- PUT /api/v1/resumes/{id}/share - Update sharing permission
- DELETE /api/v1/resumes/{id}/share - Remove sharing
- GET /api/v1/teams/{id}/resumes - List resumes shared with team

Request models:
- ShareResumeRequest: team_id, permission (view/edit)

Response models:
- ResumeShareResponse: resume_id, team_id, permission, shared_by, shared_at

Permission logic:
- Only resume owner can share
- Edit permission allows team members to modify resume
- View permission allows read-only access
</action>

  <done>Sharing endpoints implemented</done>
