# Phase 8: Export Enhancements - Plan 01

**Goal:** Implement JSON export functionality for developer workflows and version control.

**Requirement:** JOB-08

**Success Criteria:**
1. JSON export API endpoint (`/v1/export/json`)
2. Frontend `exportToJSON()` function
3. Structured resume data following JSON Resume schema
4. Include metadata (version, timestamp, tailoring info)
5. Download trigger with proper file naming

**Dependencies:** Phase 5 (Enhanced Export infrastructure)

**Out of Scope:** HTML export (Plan 02), PDF templates (Plan 03)

---

## Tasks

### Task 1: Research JSON Resume Schema

**What:** Evaluate JSON Resume schema standard for compatibility

**Resources:**
- JSON Resume schema (https://jsonresume.org/schema/)
- Resume schema on GitHub
- Existing resume data structure in `types.ts`

**Verification:**
- Schema compatibility documented
- Mapping strategy defined (internal → JSON Resume)

**Automation:** Claude will research and document schema mapping

---

### Task 2: Create JSON Exporter (Backend)

**What:** Build Python module to convert resume data to JSON

**Implementation:**
- Create `resume-api/lib/exporters/json_exporter.py`
- Map `SimpleResumeData` to JSON Resume format
- Include metadata (export timestamp, version, tailoring changes)
- Add type hints and validation

**Verification:**
- Exporter module created
- Unit tests pass
- JSON output validates against schema

**Files to create:**
- `resume-api/lib/exporters/json_exporter.py`
- `resume-api/lib/exporters/__init__.py` (update)

---

### Task 3: Add JSON Export API Endpoint

**What:** Create REST API endpoint for JSON export

**Implementation:**
- Add `POST /v1/export/json` endpoint
- Accept resume data in request body
- Return JSON with proper headers
- Add rate limiting (10 req/min)
- Include error handling

**Verification:**
- Endpoint responds with valid JSON
- Headers set correctly (`Content-Type: application/json`)
- Content-Disposition header for download
- Rate limiting works

**Files to modify:**
- `resume-api/routes/export.py`

---

### Task 4: Create Frontend JSON Export Utility

**What:** Build TypeScript function to trigger JSON download

**Implementation:**
- Create `src/utils/export-json.ts`
- Call `/v1/export/json` API endpoint
- Create Blob and trigger download
- Handle errors gracefully
- Add TypeScript types for JSON Resume format

**Verification:**
- Function triggers file download
- File named correctly (`resume-export-YYYY-MM-DD.json`)
- JSON is valid and parseable
- Error handling works

**Files to create:**
- `src/utils/export-json.ts`
- `types/json-resume.ts` (types for JSON Resume schema)

---

### Task 5: Integrate JSON Export into UI

**What:** Add JSON option to export dialog

**Implementation:**
- Add "JSON" button to ExportDialog component
- Group with other export formats
- Add tooltip explaining use case
- Wire to `exportToJSON()` function
- Show success/error toast

**Verification:**
- JSON option visible in export dialog
- Click triggers download
- Success toast appears
- Error handling shows actionable message

**Files to modify:**
- `components/ExportDialog.tsx`
- `components/ExportButton.tsx` (if exists)
