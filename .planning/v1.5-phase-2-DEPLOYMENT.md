## Scheduled Jobs

### Configure Aggregation Scheduler

```python
# Add to main.py or dedicated scheduler

from apscheduler.schedulers.asyncio import AsyncIOScheduler
from lib.jobs.aggregator import JobAggregator

scheduler = AsyncIOScheduler()

async def run_aggregation():
    """Run job aggregation."""
    db = next(get_db_session())
    try:
        aggregator = JobAggregator(db)
        
        # Get due sources
        due_sources = await aggregator.schedule_fetch(max_age_minutes=60)
        
        for source in due_sources:
            await aggregator.fetch_source(source.id)
            
    finally:
        db.close()

# Schedule to run every 15 minutes
scheduler.add_job(
    run_aggregation,
    'interval',
    minutes=15,
    id='job_aggregation',
    replace_existing=True,
)

scheduler.start()
```

### Metrics to Track

```python
# Job aggregation metrics
jobs_sources_active_total
jobs_sources_fetch_total
jobs_sources_fetch_failed_total
jobs_postings_fetched_total
jobs_postings_duplicates_removed_total

# Search metrics
jobs_search_requests_total
jobs_search_latency_seconds

# Saved jobs metrics
jobs_saved_total
jobs_unsaved_total
```

### Alert Configuration

```yaml
# Prometheus alerts
groups:
  - name: job_aggregator
    rules:
      - alert: JobSourceFetchHighErrorRate
        expr: rate(jobs_sources_fetch_failed_total[5m]) / rate(jobs_sources_fetch_total[5m]) > 0.2
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Job source fetch error rate high"
          
      - alert: JobSearchHighLatency
        expr: histogram_quantile(0.95, rate(jobs_search_latency_seconds_bucket[5m])) > 2
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Job search latency high"
          
      - alert: JobDeduplicationRateHigh
        expr: rate(jobs_postings_duplicates_removed_total[5m]) / rate(jobs_postings_fetched_total[5m]) > 0.5
        for: 15m
        labels:
          severity: warning
        annotations:
          summary: "Job deduplication rate unusually high"
```
