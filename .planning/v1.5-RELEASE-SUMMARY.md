## 🔌 New API Endpoints

### LinkedIn Integration
```
POST /api/v1/linkedin/connect      # Initiate OAuth
GET  /api/v1/linkedin/callback     # OAuth callback
GET  /api/v1/linkedin/status       # Connection status
POST /api/v1/linkedin/disconnect   # Disconnect
GET  /api/v1/linkedin/profile      # Get profile
POST /api/v1/linkedin/refresh      # Refresh profile
```

### Job Aggregator
```
GET  /api/v1/jobs/search           # Search jobs
GET  /api/v1/jobs/recommendations  # Recommendations
POST /api/v1/jobs/save             # Save job
GET  /api/v1/jobs/saved            # Get saved jobs
DELETE /api/v1/jobs/saved/{id}     # Remove saved job
GET  /api/v1/jobs/sources          # List sources
```

### Job Alerts
```
GET  /api/v1/alerts                # List alerts
POST /api/v1/alerts                # Create alert
PUT  /api/v1/alerts/{id}           # Update alert
DELETE /api/v1/alerts/{id}         # Delete alert
POST /api/v1/alerts/{id}/pause     # Pause alert
POST /api/v1/alerts/{id}/resume    # Resume alert
GET  /api/v1/alerts/preferences     # Get preferences
PUT  /api/v1/alerts/preferences     # Update preferences
```

### Application Tracking
```
GET  /api/v1/applications          # List applications
POST /api/v1/applications          # Create application
GET  /api/v1/applications/{id}     # Get application
PUT  /api/v1/applications/{id}     # Update application
DELETE /api/v1/applications/{id}   # Delete application
POST /api/v1/applications/{id}/status # Update status
GET  /api/v1/applications/stats    # Statistics
GET  /api/v1/applications/funnel   # Funnel data
GET  /api/v1/applications/conversion # Conversion rates
POST /api/v1/applications/autofill # Auto-fill
```

## 🔧 Configuration

### Environment Variables

```bash
# LinkedIn OAuth
LINKEDIN_CLIENT_ID=your_client_id
LINKEDIN_CLIENT_SECRET=your_client_secret
LINKEDIN_REDIRECT_URI=http://localhost:3000/auth/linkedin/callback

# Job Sources
ADZUNA_APP_ID=your_app_id
ADZUNA_APP_KEY=your_app_key

# Email/SMS
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your_smtp_user
SMTP_PASSWORD=your_smtp_password
TWILIO_ACCOUNT_SID=your_account_sid
TWILIO_AUTH_TOKEN=your_auth_token

# Scheduler
ALERT_SCHEDULER_ENABLED=true
INSTANT_ALERT_INTERVAL=15
```
