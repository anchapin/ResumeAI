# Requirements: ResumeAI - Job Application Workflow

**Defined:** 2026-03-12
**Core Value:** Enable end-to-end job application workflow from base resume to tailored resume and cover letter

## v1.1 Requirements

### Job Description Input

- [x] **JOB-01**: User can input job description via text paste or URL fetch, with validation and parsing

### AI Tailoring

- [x] **JOB-02**: AI tailors resume content to match job description with accept/reject changes

### Cover Letter

- [x] **JOB-03**: AI generates personalized cover letter with tone options and editable preview

### Export Formats

- [x] **JOB-04**: Export tailored resume as DOCX with proper formatting
- [x] **JOB-05**: Export tailored resume as TXT and Markdown (MD) formats

### GitHub Integration

- [ ] **JOB-06**: Import projects from GitHub account to enhance resume

### Manual Editing

- [ ] **JOB-07**: Manual editing interface for tailored content with version history

## Out of Scope

| Feature                  | Reason                                |
| ------------------------ | ------------------------------------- |
| Job matching scoring     | Analytics feature for future release  |
| Resume ATS checking      | Separate feature in backlog           |
| Interview preparation    | Out of scope for job application flow |
| Salary negotiation tips  | Content feature, not workflow         |
| Multiple resume variants | v1.2 consideration                    |
| Real-time collaboration  | Not needed for individual workflow    |
| Cover letter templates   | Simple generation is sufficient       |
