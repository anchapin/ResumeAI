# Phase 7: Manual Tailoring Editor - Plan 02

**Goal:** Implement version history with undo/redo functionality for editor changes.

**Requirement:** JOB-07

**Success Criteria:**
1. Undo/redo buttons in editor toolbar
2. Keyboard shortcuts (Ctrl+Z, Ctrl+Shift+Z)
3. Version snapshots saved before AI changes
4. Ability to revert to previous version
5. Visual indicator of available undo/redo states

**Dependencies:** Plan 01 (Rich Text Editor)

**Out of Scope:** Change tracking UI (Plan 03)

---

## Tasks

### Task 1: Add Undo/Redo to RichTextEditor

**What:** Implement undo/redo stack in editor component

**Implementation:**
- Use editor library's built-in undo/redo if available
- Add Undo/Redo buttons to toolbar
- Disable buttons when stack is empty
- Add keyboard shortcuts (Ctrl+Z, Ctrl+Shift+Z)
- Track stack depth

**Verification:**
- Undo button disabled at initial state
- After edits, undo button becomes enabled
- Ctrl+Z reverses last change
- Ctrl+Shift+Z redoes undone change
- Visual feedback on button states

**Files to modify:**
- `src/components/editor/RichTextEditor.tsx`
- `src/components/editor/EditorToolbar.tsx`

---

### Task 2: Add Version History to Resume Store

**What:** Track resume state snapshots in Zustand store

**Implementation:**
- Add `versionHistory` array to store state
- Add `saveSnapshot()` action to capture current state
- Add `restoreSnapshot(index)` action to revert
- Add `getSnapshot(index)` selector
- Limit history to last 20 snapshots (memory management)

**Verification:**
- Snapshots saved before AI tailoring
- Can restore previous snapshot
- History limited to 20 entries
- Oldest snapshots removed when limit exceeded

**Files to modify:**
- `src/store/resume-store.ts`
- `src/store/types.ts`

---

### Task 3: Create Version History Panel

**What:** UI component to view and restore previous versions

**Implementation:**
- Create `src/components/editor/VersionHistoryPanel.tsx`
- List snapshots with timestamps
- Show preview of changes (optional diff view)
- Add "Restore this version" button
- Add confirmation dialog before restore

**Verification:**
- Panel shows list of saved versions
- Each version shows timestamp and change type
- Clicking restore shows confirmation
- After restore, editor shows previous content

**Files to create:**
- `src/components/editor/VersionHistoryPanel.tsx`
- `src/components/editor/VersionHistoryPanel.test.tsx`

---

### Task 4: Auto-Snapshot Before AI Changes

**What:** Automatically save version before applying AI suggestions

**Implementation:**
- Add snapshot call before `applyAITailoring()` in store
- Label snapshot with "Before AI tailoring" + timestamp
- Add metadata: change type, affected sections
- Show notification: "Saved version before AI changes"

**Verification:**
- Snapshot created before AI tailoring
- Snapshot labeled correctly
- User can restore pre-AI version
- Notification appears

**Files to modify:**
- `src/store/resume-store.ts`
- `src/utils/ai-tailoring.ts`

---

### Task 5: Add Manual Snapshots

**What:** Allow users to manually save versions

**Implementation:**
- Add "Save Version" button in editor toolbar
- Prompt for optional version name/description
- Save to version history
- Show success toast

**Verification:**
- Button visible in toolbar
- Clicking opens name input dialog
- Version saved with custom name
- Appears in version history panel

**Files to modify:**
- `src/components/editor/EditorToolbar.tsx`
- `src/store/resume-store.ts`

---

### Task 6: Keyboard Shortcuts Integration

**What:** Add global keyboard shortcuts for undo/redo

**Implementation:**
- Use existing shortcut hook or create new one
- Register Ctrl+Z for undo
- Register Ctrl+Shift+Z for redo
- Prevent default browser behavior in editor
- Show shortcuts in tooltip on hover

**Verification:**
- Ctrl+Z works in editor
- Ctrl+Shift+Z works in editor
- Shortcuts don't interfere with text input
- Tooltips show shortcut hints

**Files to modify:**
- `src/hooks/useKeyboardShortcuts.ts`
- `src/components/editor/EditorToolbar.tsx`
