# Phase 8: Export Enhancements - Plan 02

**Goal:** Implement HTML export for web portfolios and personal websites.

**Requirement:** JOB-09

**Success Criteria:**
1. HTML export API endpoint (`/v1/export/html`)
2. Self-contained HTML with embedded CSS
3. Responsive design for all screen sizes
4. Print-friendly styles
5. Portfolio-ready visual design
6. Optional dark mode support

**Dependencies:** Phase 5 (Export infrastructure), Plan 01 (JSON export patterns)

**Out of Scope:** PDF templates (Plan 03), Interactive features (future phase)

---

## Tasks

### Task 1: Research HTML Resume Templates

**What:** Evaluate modern HTML resume patterns and best practices

**Resources:**
- HTML5 semantic structure
- Responsive resume templates
- Print CSS best practices
- Accessibility guidelines (WCAG 2.1)

**Verification:**
- Design decisions documented
- Template structure planned
- Color scheme defined

**Automation:** Claude will research and recommend best practices

---

### Task 2: Create HTML Template

**What:** Build HTML template with embedded CSS for resume export

**Implementation:**
- Create `resume-api/templates/resume.html`
- Use semantic HTML5 (header, section, article, footer)
- Embed CSS in `<style>` tag for portability
- Include responsive breakpoints
- Add print media queries
- Support dark mode via `prefers-color-scheme`

**Verification:**
- Template renders correctly in browser
- Responsive on mobile/tablet/desktop
- Print preview looks professional
- Dark mode detected and applied

**Files to create:**
- `resume-api/templates/resume.html`
- `resume-api/templates/css/resume-styles.css`

---

### Task 3: Create HTML Exporter (Backend)

**What:** Build Python module to generate HTML from resume data

**Implementation:**
- Create `resume-api/lib/exporters/html_exporter.py`
- Use Jinja2 templating (already in use)
- Map resume sections to HTML structure
- Include metadata in `<head>` (SEO-friendly)
- Add Open Graph tags for social sharing

**Verification:**
- Exporter generates valid HTML5
- All resume sections rendered
- CSS embedded correctly
- No external dependencies

**Files to create:**
- `resume-api/lib/exporters/html_exporter.py`

**Files to modify:**
- `resume-api/lib/exporters/__init__.py`

---

### Task 4: Add HTML Export API Endpoint

**What:** Create REST API endpoint for HTML export

**Implementation:**
- Add `POST /v1/export/html` endpoint
- Accept resume data in request body
- Return HTML with proper headers
- Set `Content-Type: text/html`
- Add rate limiting (10 req/min)

**Verification:**
- Endpoint returns valid HTML
- Headers configured correctly
- File download triggered
- Rate limiting enforced

**Files to modify:**
- `resume-api/routes/export.py`

---

### Task 5: Create Frontend HTML Export Utility

**What:** Build TypeScript function to trigger HTML download

**Implementation:**
- Create `src/utils/export-html.ts`
- Call `/v1/export/html` API endpoint
- Create Blob with HTML content
- Trigger download with `.html` extension
- Handle errors gracefully

**Verification:**
- Function triggers file download
- File named `resume-YYYY-MM-DD.html`
- HTML opens correctly in browser
- Error handling works

**Files to create:**
- `src/utils/export-html.ts`

---
