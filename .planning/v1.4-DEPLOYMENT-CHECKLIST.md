## Deployment Steps

### 1. Deploy Infrastructure

```bash
# Deploy LanguageTool
docker-compose up -d languagetool

# Verify LanguageTool
curl http://localhost:8081/v2/check \
  -H "Content-Type: application/json" \
  -d '{"text": "test", "language": "en-US"}'

# Deploy Redis
docker-compose up -d redis

# Verify Redis
docker-compose exec redis redis-cli ping
# Should return: PONG
```

### 2. Run Database Migrations

```bash
cd resume-api

# Create new migration (if needed)
alembic revision --autogenerate -m "Add writing_suggestions table"

# Run migrations
alembic upgrade head

# Verify migrations
alembic current
```

### 3. Deploy API

```bash
# Build and deploy
docker-compose build resume-api
docker-compose up -d resume-api

# Check health
curl http://localhost:8000/api/v1/health

# Should return: {"status": "healthy", "version": "1.4.0"}
```

### 4. Deploy Frontend

```bash
# Build
npm run build

# Deploy (Vercel example)
vercel --prod

# Or deploy to your hosting provider
```

### 5. Verify Deployment

```bash
# Health check
curl https://api.resumeai.com/api/v1/health

# Test Writing Assistant
curl -X POST https://api.resumeai.com/api/v1/writing/suggest \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"text": "Led development", "cursor_position": 15}'

# Test Skills Extraction
curl -X POST https://api.resumeai.com/api/v1/skills/extract \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"text": "Python developer with AWS experience"}'

# Test Auto-Complete
curl -X POST https://api.resumeai.com/api/v1/autocomplete/suggest \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"text": "Led ", "cursor_position": 4}'

# Test Resume Scoring
curl -X POST https://api.resumeai.com/api/v1/scoring/score \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"resume_data": {...}, "role": "Engineer"}'
```

## Rollback Procedure

If issues occur:

### 1. Stop New Deployment

```bash
# Stop new containers
docker-compose down resume-api
```

### 2. Restore Previous Version

```bash
# Deploy previous version
docker-compose up -d resume-api:1.3.0
```

### 3. Verify Rollback

```bash
# Check health
curl http://localhost:8000/api/v1/health

# Verify version
curl http://localhost:8000/api/v1/health | jq .version
# Should return: "1.3.0"
```

### 4. Notify Stakeholders

- [ ] Notify team of rollback
- [ ] Document issues found
- [ ] Create incident report
- [ ] Schedule post-mortem
